# 图表与导航交接（2026-10-03）

本轮只调整现有 Liquid Glass 前端的图表呈现和页面跳转。沿用服务器专用入口、现有账本、模型与服务；当前改动已纳入 gonghang 仓库发布快照。设计约定见 `AI_accounting_agent/frontend/liquid-glass/DESIGN.md`。

2026-10-04 补充：日期区间带入记账助手；规划回源账本顶部显示实际日期，分类/搜索有独立金额小计。目标保留“安排资金”入口并增加进度记录/撤销。19 页保持 430px 竖版，导航材质由最后加载的 `glass.css` 统一。

## 图表

- 收支图表按日期选择、结余、趋势、分类、目标与分析排列。所有屏幕保持原有 430px 最大宽度的竖版单列 App，宽屏居中；趋势绘图区随实际卡片宽度变化。
- 折线和柱状均显示完整所选区间；金额轴有真实刻度，日期轴最多五个标记。键盘或点击数据点可读取精确数值。金额隐藏时同时移除图形。
- 分类占比和上期对比共用一个卡片，默认显示前五项，其余可展开。所有分类仍参与计算，没有因折叠而改变总额。
- 分类颜色固定；小额刻度、缺失值、单点、空区间和长区间都有独立处理。投资可视化与风险观察沿用相同排版规则。
- “详细分析”继承当前图表的日期区间；“历史持仓”进入投资研究的历史组合。

## 导航

`navigation.js` 集中定义 19 个路由的标题、导航栏归属和直接访问时的返回目标。

| 主导航 | 相关页面 |
| --- | --- |
| 首页 | 体验账户、操作保护 |
| 账本 | 记一笔、导入流水 |
| 图表 | 财务分析 |
| 助手 | 记账、规划与投研聊天 |
| 投资 | 资金规划、投资研究、模拟持仓、我的计划、方案比较、投资可视化、风险观察、个股研究 |

设置及“一起改进”沿用实际入口的导航归属。除首页外，左上返回按钮优先回到实际来源；直接打开子页面时返回其父页面。底部五个入口作为独立导航起点，交叉链接到祖先页面时缩短路径，避免返回循环。

投资与账本的数据关系及模拟资产区分见 [INVESTMENT-REFACTOR.md](INVESTMENT-REFACTOR.md)。

浏览器前进/后退与页面返回共用历史状态，并恢复滚动位置。记账、聊天、个人计划、连接设置、导入文件及自定义日期在页面切换时保留未提交内容。保留表单不等于提交；主动丢弃、解析替换和成功保存后的新草稿优先于旧表单内容。

## 验证

- `tests/navigation.test.mjs`：返回路径、父页面回退、导航归属、前进/后退、滚动状态。
- `tests/chart_geometry.test.mjs`、`tests/visuals.test.mjs`：图表几何、完整数据、小额刻度、颜色、缺失值和数值计算。
