# 青财安全自评

## 安全目标与权限

保护的对象为体验账户本金、确认状态、银行回执、用户账本和训练反馈。本原型单用户，没有把固定 actor 解释为正式银行登录。入口的专用链接与客户端限制是比赛访问控制，不能替代真实身份认证。

| 主体 | 可读 | 可写/授权 | 不能做什么 |
|---|---|---|---|
| LLM | 最小化对话、画像汇总 | 意图草稿、已知原因排序 | 不能签发身份、确认、MFA、回执或发布模型 |
| 浏览器 | 当前 owner 的账本、计划、历史结果 | 提交参数、确认挑战、真实验证码、反馈同意与审核 | 不能选择 actor、私钥、策略或改动已核对参数 |
| 理财 BFF | 私有会话、可信事实、安全状态 | 按实际用户事件签发独立控制证明 | 不接受聊天文字或模型字段作为授权 |
| MOSAIC 网关 | 新鲜事实、策略、来源、控制证明 | 核验义务、预留、单次执行、审计与回执 | 未满足任一条件时不派发写操作 |
| 银行模拟器 | 体验账户持久状态 | 整数分转移、请求唯一结果 | 不制造理财收益或连接真实账户 |
| 离线维护者 | 审核反馈、固定数据、评测产物 | 训练、哈希登记、发布与回滚 | 网页和对话不能调用此权限 |

## 实际防护

1. 入口校验 Host、专用凭据、客户端地址与修改请求 Origin，固定代理至本项目；不暴露任意代理功能。
2. 理财 API 使用 8 小时服务端会话、HttpOnly / SameSite=Strict cookie 和精确 Origin / CSRF。身份令牌有效期不超过会话。
3. 六个密钥角色独立；目录 0700、密钥和 SQLite 0600。策略、密钥指纹固定在可信本地状态；模型输出不提升来源可信度。
4. 参数表与确认分开；控制证明绑定 actor、session、target、动作摘要和短时效。执行前再次读取事实与策略。
5. 动态码需实际注册、真实校验，已用 counter 不可复用；失败限速与短时封锁。不把“模型已确认”变为确认凭证。
6. 预留、银行唯一请求与回执持久化。结果未知暂停自动重试；重启恢复、跨会话核账和绑定新挑战的恢复流程独立于支付。
7. 自由文本转义；私密模式隐藏金额、图表和对话，敏感确认须主动显示。模型输入按规则最小化；登记联系人的手机号先转换为安全别名，其他手机号仍遮盖。
8. 行情异常记录先隔离，研究报告只能选取可信事实 ID；用户只导入收入时不能据此开放长期产品。账单编辑校验版本，目标进度绑定目标 ID，避免旧页面覆盖与串用。
9. 数据飞轮默认关闭、逐条审核、结构化最小化、固定留出和发布哈希检查。无网页自动训练或自动部署。

## 攻击与故障验证

| 情形 | 预期行为 | 证据 |
|---|---|---|
| 模型输出 confirmed / 浮点金额 / 陌生收款人 | 拒绝格式或追问，银行副作用为零 | `test_finance_workspace.py`、真实模型案例报告 |
| 伪造来源、用户确认、MFA | 未满足义务不派发 | MOSAIC 原包复现及应用确认测试 |
| Origin / CSRF / actor 篡改 | 403 / 422；不能产生支付 | 应用及入口测试 |
| 改金额复用请求 ID、重复点击 | 冲突拒绝或返回原结果；只一笔 | 应用测试及实际 Chromium |
| 累计金额越阈值、复用动态码 | 要求验证；已用码拒绝 | 应用及实际 Chromium |
| 原会话过期后新会话确认旧动作 | 不继承授权；允许只读历史核账 | 过期会话测试 |
| 已扣款、回执写入失败、重启 | 未知→暂停→核账→验证恢复，无二次扣款 | `test_post_bank_commit_receipt_fault_survives_restart_without_second_debit` |
| 解释器编造金额、遗漏风险或新增授权 | 丢弃输出，使用已核对事实，无资金副作用 | 画像解释测试 |
| 多笔描述 / 工资单独导入 / 旧目标进度 | 明确拆分、限制资格、拒绝旧目标写入 | `test_judge_fixes.py` 与隔离浏览器 |
| 无效 OHLC / 模型虚构数字 | 异常行不参与，模型输出回退为可核对事实 | 行情校验与报告回归 |
| 并发账单修改 | 版本冲突拒绝，保留原记录与导入身份 | 原 ID 编辑回归 |
| 退出、伪造反馈、修改发布产物 | 未训练反馈删除/无候选；哈希不符不发布 | 反馈与模型发布测试 |

当前证据在生成的 `VALIDATION.json` 中。原安全包 277 项通过、4 项 Docker 可选跳过；应用回归另列。通过测试不等于已完成银行级审计，真实模型攻击样例不等于广义攻击成功率。

## 已知风险与后续接入条件

| 边界 | 当前限制 | 接真实银行前的工作 |
|---|---|---|
| 身份和传输 | 私网 HTTP、固定 owner、同一维护主机 | 正式用户认证、独立 MFA、HTTPS、租户隔离、授权记录 |
| 主机与密钥 | 同机持有密钥和信任根 | KMS/HSM、轮换、外部审计锚点、备份与恢复演练 |
| 信息最小化 | 规则遮盖并非任意自由文本匿名化 | 数据分类、用途授权、保留期、删除和脱敏评审 |
| 未知银行结果 | 无可信银行回执时保持未知 | 银行对账协议、人工工单、权限分离；禁止盲目重发 |
| 模型错误 | 会误解口语；以草稿、参数和确认限制后果 | 扩充独立案例、人工评审、漂移检测与版本回退 |
| 资金建议 | 原型问卷和不完整流水，不构成适当性结论 | 真实产品与适当性流程、专业审查；不可承诺收益 |
| CSV 去重 | 无银行编号时只能判断精确匹配 | 银行唯一流水标识与更完整人工合并流程 |
| 界面隐私 | 浏览器 localStorage 存个人草稿和对话 | 正式账号隔离、客户端保留/清理、端点认证与加密 |

安全包 MIT 归属见 `ATTRIBUTION.md`。本项目新增的是与真实网页用户事件、反馈和个人计划的衔接，不把第三方内核描述为本队从零开发。
