核验日期：2026-10-04。作品名称：**FinPilot——可解释财富管理智能体**。

## 结论与作品定位

**现有作品与「财富管理服务」方向相符，比原来的青年群体定位更贴合当前主线，可以按该方向组织参赛材料。** 这是一项基于方向说明和现有实现的评估，不是组委会资格审核或评分结论。

作品以个人现金流为起点，把账单核对、生活目标、资金预留、风险偏好、方案比较和用户确认连接起来。记账提供事实，模型解释已有依据，投资研究提供可追溯的历史资料，模拟银行展示执行边界。青年用户可以作为首批体验对象，年龄不再是作品的主分类。

推荐申报简介：

> FinPilot 是面向普通个人用户的可解释财富管理智能体。系统将可校正的银行流水转化为现金流分析，结合生活开销、还款、应急金目标、用款期限与风险偏好，形成可核对的资金安排，并展示方案比较与模拟操作。模型负责理解意图和组织解释，金额计算、资格约束及操作授权由服务器和用户控制。当前为个人资金管理原型，使用模拟本金与历史研究数据。

## 建议补强顺序

以下是根据赛道定位提出的产品建议，**不是官方硬性参赛条件，也未因本次更名自动实现**。

1. **让用户看懂选择。** 在方案比较和研究图表增加点击可见的术语解释：具体含义、可能损失、何时能取出、费用从哪里扣。保持界面简洁，不重新堆放常驻小字。使用可靠来源和数据日期，解释未知项，不能把模拟产品的即时赎回、零费用说成真实产品规则。
2. **把存量与流量分开。** 增加用户主动填写并标注来源日期的现金、投资、负债余额和已有应急金，再展示净资产与可动用资金。当前账本月结余、目标累计、模拟本金和历史组合不能相加成真实总资产。
3. **展示方案为何适合。** 在既有期限测算上，补充费用后金额、提前用款约束和假设亏损情景；说明假设、来源及不确定性。随后才考虑多目标、多资产方案和偏离提醒。
4. **验证理解效果。** 用合成材料招募自愿体验者，比较能否识别风险、期限和费用，是否理解不可安排资金，记录任务完成率与误操作。没有实际执行前，材料只写验证计划。

推荐演示顺序：核对流水 → 查看可安排资金的依据 → 设置目标与期限 → 比较风险／期限／费用 → 查看不适合原因 → 模拟操作与回执。安全保护支撑财富管理主线，不占据整场答辩。
