# 工行杯 · 财富管理服务适配评估

核验日期：2026-10-04。作品名称：**FinPilot——可解释财富管理智能体**。

## 结论与作品定位

**现有作品与「财富管理服务」方向相符，比原来的青年群体定位更贴合当前主线，可以按该方向组织参赛材料。** 这是一项基于方向说明和现有实现的评估，不是组委会资格审核或评分结论。

作品以个人现金流为起点，把账单核对、生活目标、资金预留、风险偏好、方案比较和用户确认连接起来。记账提供事实，模型解释已有依据，投资研究提供可追溯的历史资料，模拟银行展示执行边界。青年用户可以作为首批体验对象，年龄不再是作品的主分类。

推荐申报简介：

> FinPilot 是面向普通个人用户的可解释财富管理智能体。系统将可校正的银行流水转化为现金流分析，结合生活开销、还款、应急金目标、用款期限与风险偏好，形成可核对的资金安排，并展示方案比较与模拟操作。模型负责理解意图和组织解释，金额计算、资格约束及操作授权由服务器和用户控制。当前为个人资金管理原型，使用模拟本金与历史研究数据。

## 本轮已补齐与待验证项

1. **降低理解门槛已实现。** 资产、规划、方案比较和助手有按需词条入口；每个词条说明含义、数字例子与适用边界，基础金融概念链接官方资料。词库可搜索，费用试算展示扣费后的参与金额、期末金额及变化；默认不堆放说明小字。
2. **个人财富视图已实现。** 投资新增「资产总览」：手动登记人民币现金、存款、基金、股票、债券、养老、房产和其他资产，以及信用卡、贷款和其他负债。净资产与可动用现金分别计算，资产分布可视化，估值和完整性有复核状态。
3. **账本联动有明确依据。** 个人账本的应急目标与已登记预留对照，展示缺口；同时看月均结余，但不把月结余、目标进度、模拟本金、历史组合相加成个人余额。登记或试算不会自动买卖。
4. **真实用户理解效果仍待验证。** 建议邀请自愿体验者完成“分清净资产与现金、解释回撤、核对费用、识别待核对资金”四项任务。记录答对率、误解类型和完成时间；没有实际执行前只写验证计划。多目标优化、真实产品接入与家庭协作仍属后续范围。

这些是基于方向说明的产品设计与实施，不是官方额外报名门槛。新增证据见 [`test_wealth.py`](../../tests/test_wealth.py)、[`e2e_wealth.py`](../../tests/e2e_wealth.py) 和 [`PUBLISH-VALIDATION.json`](../../materials/PUBLISH-VALIDATION.json)。

推荐演示顺序：核对流水 → 查看资金规划 → 登记资产与负债并核对可用现金 → 点开风险解释 → 试算涨跌和费用 → 模拟操作与回执。安全保护支撑财富管理主线，不占据整场答辩。
