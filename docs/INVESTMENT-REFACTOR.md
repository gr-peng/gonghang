# 投资与账本流程（2026-10-04）

底部入口恢复为“投资”。保留原有 430px 竖版 Liquid Glass；投资模块按资产总览、资金规划、投资研究、模拟持仓四段组织，共 20 个路由。

## 页面关系

- 首页“结余规划”、账本“资金规划”、图表目标“安排资金”均进入资金规划。
- 规划首卡使用与账本相同范围、相同月份的收支报告。可查看对应账单、图表及历史计算依据并返回。调整目标但不切换账本范围时保留所选月份。
- 投资研究保留自选、个股日报、关注、历史组合、净值、配置、回测和风险。历史持仓详情使用快照，不请求该证券尚不支持的行情接口。
- 模拟持仓统一显示模拟现金、产品本金、申购/赎回、体验账户和操作记录。方案比较可进入模拟持仓；执行仍须独立核对和必要的动态码。
- 助手分为记账、规划、投研。规划问题优先解释结余、目标和应急安排，后续按钮可进入补充流水、计划或方案比较。

## 金额依据

| 数字 | 来源与用途 |
| --- | --- |
| 所选月份结余 | 同范围账本收入减支出，随月份改变 |
| 目标预留后月均结余 | 最近六个完整月份中有记录月份的月均现金流与用户计划，用于估算月度安排 |
| 模拟现金及产品本金 | 独立持久化模拟账户，用于体验申购/赎回 |

历史组合是另一个带日期的研究快照，不与上述金额合并。账单增加不会给模拟账户充值，记录目标进度不会产生交易。

`finance_workspace.ledger_planning()` 返回只读 `overview.planning`，金额均为整数分：

```text
固定开销补足 = max(0, 设置的固定开销 − 月均原支出)
月均可安排 = max(0, 月均结余 − 固定开销补足 − 未计入账单的月还款)
目标剩余 = max(0, 目标金额 − 手动记录进度)
目标每月所需 = 向上取整到分(目标剩余 / 设置的规划月数)
目标每月已分配 = min(月均可安排, 目标每月所需)
目标缺口 = 目标每月所需 − 目标每月已分配
目标预留后月均结余 = max(0, 月均可安排 − 目标每月所需)
```

退款抵减净支出，原支出用于应急目标和固定开销去重。内部转账、本金划转、非人民币和未完成的当月不进入月均窗口。缺失月不计入分母，有记录不等于完整银行流水。应急金已预留额来自独立手动资产登记，未知时保持待核对，不能用模拟余额宣称已备足。规划月数是当前设置，不是自动倒计时。

旧目标月度预留与可行性字段同步按剩余目标计算；模拟交易仍保守保留原全额目标缓冲，手动增加进度不能提高申购额度。未改 MOSAIC 内核、确认、MFA、幂等或恢复规则。

## 评审修复

月均安排需支出覆盖或明确的生活开销下限、还款信息及用户完整性确认。只有工资时显示待核对，不开放长期资格；实际应急储备仍未知。目标 ID 隔离、替换确认、进度撤销、期限只读测算已补齐。账单可原 ID 编辑，筛选显示小计，规划回源显示实际起止日期。投研过滤无效 OHLC，报告只选择已核对事实。详见 [评审修复验收](competition/REVIEW-FIXES.md)。
