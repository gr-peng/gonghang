# FinPilot · Quiet Glass 数据界面

本规范延续当前 Liquid Glass，参考 Stitch Design Taste 的层级、留白、网格与交互原则。用户的简洁要求优先：数据图表不使用装饰照片、无穷动效或常驻教程文案。所有图形展示真实 API 数据，不为构图虚构数字。

## 氛围与层级

轻、安静、清楚。密度适中，视觉重心由结余和趋势形成。首屏先看到期间、结余、收入与支出，再看到完整趋势。不要把日期、比较和说明拆成多张同等重量的卡片。

## 色彩与文字

- 画布 #f4f6f9；白色半透明表面；文字 #17212b；辅助数据 #566477。
- 导航延续原蓝色 #1d4ed8。图表支出为低饱和蓝 #4665b4，收入为鼠尾草绿 #789889；颜色承担数据语义。
- 分类颜色按名称固定，换月份不改含义。细网格 #edf0f5，只保留必要刻度。
- 中文优先平台原生无衬线字体，避免外部字体网络依赖。金额用等宽数字，结余 32–36px，卡片标题 16–17px，交互与分类正文 13–15px。
- 不使用纯黑、霓虹光晕、渐变文字、假精度、夸大收益和重复副标题。

## 图表与卡片

圆角 28–30px，内边距 20–28px，柔和阴影。只用轻微冷色渐变突出结余，收入/支出用分隔和留白，不再嵌套两张灰卡。

完整月份在容器中展示，日期刻度抽稀，不能裁掉月底或默认强制横向滚动。曲线为保真的直线连接，点在操作后显现；保留键盘与精确读数。对比条的相同长度必须代表相同金额。

支出“占比 / 对比”共享一个分析区。圆环薄且有分隔，中心只留合计；先呈现金额最高的五类，其余显式展开，全部数据和分类钻取始终可用。

## 布局和操作

所有页面始终保留原有竖版 App 比例：统一使用 tokens.css 的 430px 最大宽度，宽屏居中，小屏随屏幕收窄，卡片自上而下排列。电脑、平板也不得把图表、投资或风险页面扩成宽版或多列仪表盘；页面切换不改变外框宽度。保留五项底部导航，图表保持相同数据与控件，不用缩小整页替代布局。

按钮触控区至少 44px。月份与周期整合，详细分析继承当前区间。所有非首页有左上返回键：内容链接回来源，主栏目回首页，直接打开详情有父页，浏览器前进后退和刷新可用；返回保留筛选、未提交草稿和滚动。

动画只用于简短操作反馈，尊重减少动画/透明度设置。加载用尺寸匹配的骨架，不让主要内容反复跳动。空态、隐藏金额和错误有独立可读状态，不绘制假曲线填空。

## 投资模块

底栏使用“投资”，内部三段为资金规划、投资研究、模拟持仓。账本当月结余与历史月均计划要写明口径；历史组合快照和模拟账户资产各自呈现，不混成同一个总额。计划能回到账单依据，模拟操作保留独立确认。

## 统一透明玻璃（2026-10-03）

所有页面的顶部栏、底部导航、分段选择、卡片、按钮、表单及弹窗共享 tokens.css 材质变量，由最后加载的 glass.css 统一应用。页面样式只管理布局，不能另设实心导航或黑色主按钮。

默认基底白色透明度 28%，叠加轻微斜向高光、亮边和柔和阴影；模糊从 22px 降为 8px，以清透层次代替厚磨砂。主按钮和选中项使用透明蓝色与深色文字，危险操作保留红色语义。列表行保留行式点击，不变成一排胶囊。

弹窗使用更高透明底色浓度以保证背后文字不干扰阅读；“减少透明度”、系统减少透明度偏好、不支持 backdrop-filter 的浏览器均有实色回退。继续保留原 430px 竖版比例、图表颜色及二维码白底。
